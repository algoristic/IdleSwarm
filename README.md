# IdleSwarm

Ein Idle-Browserspiel für eine Person: Der Spieler führt einen Schwarm vom Einzeller in der Ursuppe über Meer und Land bis ins All. Der Schwarm sammelt Nahrung, brütet Einheiten aus, erobert Futterstellen und entwickelt sein Genom weiter.
